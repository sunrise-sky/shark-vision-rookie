# 视频与材料说明

输入视频 [demo.mp4](demo.mp4) 随仓库提供，克隆仓库后即可从本目录读取，并在运行说明中记录实际读取方式。

| 项目 | 参数 |
| --- | --- |
| 分辨率 | 1440×1080 |
| 帧率 | 30 FPS，恒定帧率 |
| 帧数 | 686 |
| 时长 | 约 22.87 秒 |
| 编码与像素格式 | H.264/AVC，`yuv420p` |

视频保留原始 `demo.avi` 的前 686 个完整帧，已去掉末尾损坏帧，未缩放或改变帧率；原始 AVI 另行保留。

## 输入视频与结果视频

- 输入视频优先保留原始分辨率、原始帧率和目标细节。程序应读取实际 FPS，并按该帧率发布视频帧，不能为了统一格式随意改成 30 FPS。
- 若培训方提供兼容版本，建议使用 MP4 容器、H.264/AVC 编码、`yuv420p` 像素格式、恒定帧率；保留原始细节版本，避免过度压缩影响检测。
- 三种处理结果均保存为 MP4。建议采用上述兼容编码，并在运行说明中记录实际输出分辨率、帧率及编码；保存时注意所用工具对灰度图像和通道数的要求。

## 演示录像与分享

演示录屏用于展示运行过程，与算法输入和处理结果视频分开。建议 MP4 + H.264/AVC + `yuv420p`，1080p、恒定 30 FPS 可作为录屏建议；音频可选，有音频时可用 AAC，任务本身不依赖音频。

除随仓库提供的 `demo.mp4` 外，其他视频默认被忽略，不进入普通 Git 提交。需要分享其他视频时，可使用仓库 Releases 或培训方提供的材料下载链接，并在运行说明中填写真实链接。
